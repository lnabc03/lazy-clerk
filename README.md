# lazy-clerk

实习医生考勤自动签到工具。每天上午、下午自动登录医院平台完成签到，结果推送到微信。

## 三种形态

同一套签到核心，三种用法，按场景选一个：

| | 个人版 | 宿舍版 | 公网版 |
| --- | --- | --- | --- |
| 适合谁 | 自己一个人用 | 一台常开电脑服务全宿舍 | 有服务器，服务多人 |
| 人数 | 1 人 | 4–6 人 | 20 人以内 |
| 需要什么 | Windows 电脑，双击即用 | Windows 电脑，长期开机 | Linux 服务器 |
| 签到时间 | 自己定，默认 5:00 和 13:00 | 每天 5:00、13:00 后几分钟内随机 | 同左 |
| 怎么用 | 打开 exe 选菜单 | 本机浏览器里的管理页 | 网页自助注册 |
| 详细文档 | [personal](personal/README.md) | [dorm](dorm/README.md) | [server](server/README.md) |

公网版带代理逃生通道：医院封了服务器 IP 会自动换路，恢复后自动换回，
已连续多天全账号签到成功。

## 它是怎么工作的

- 医院的签到窗口是上午 5:00–8:00、下午 13:00–14:30。
- 到点自动签到。失败就每 5 分钟左右自动重试，一直试到窗口关闭才发告警；
  已经签过、今天请假，都会安静跳过。
- 微信推送：成功推送给本人；失败、需要人工处理时同时推送给本人和管理员。
- 万一当天彻底没签上，医院会在 7:00 和 14:00 提醒未签到的人，这是最后的兜底。
- 公网版额外有网络自愈：发现服务器被医院拦截时自动切换线路，恢复后自动切回。

## 风险声明（必读）

- 签到必须保存你能登录医院平台的真实密码，无法加密存放。个人版存在你自己的
  电脑上，宿舍版和公网版存在管理员的设备里。请妥善保管，不要发给别人。
- 医院平台本身是 HTTP 明文协议，密码在传输中不加密。这是医院系统的现状，
  本工具无法改变。
- 本工具只替代本人按时到岗后的例行点击，不支持也不应用于虚构出勤。
- 使用前请自行确认所在单位对自动化签到的管理规定。

## 仓库结构（开发者）

技术栈：Python 3.11+ / FastAPI / SQLite / httpx，pytest 测试。

```
app/        三种形态共用的核心：登录、签到、重试、推送、网络探测
server/     公网版：网页服务、定时调度、代理通道、Docker 部署
dorm/       宿舍版：exe 与管理员页面
personal/   个人版：exe 与交互菜单
tests/      自动化测试
```

医院平台改版时只需改 `app/core/client.py`，三种形态同时生效。
设计与决策的完整记录见 [lazy-clerk 设计稿.md](lazy-clerk%20设计稿.md)。
