# lazy-clerk 个人版

实习考勤自动签到。每天在签到窗口内按你设定的时间（默认 5:00 和 13:00）自动签到，结果推送到你的微信。

## 特性

- 单 exe 双击即用，零依赖、无常驻进程（签到由 Windows 计划任务拉起，跑完即退）
- 签到时间可自定义：开启自动签到时设置两个时段的触发时刻（默认 5:00 / 13:00），
  输入会校验格式且必须落在医院签到窗口（上午 5:00–8:00、下午 13:00–14:30）内
- 首次运行配置向导：工号密码先经医院平台真实验证，填错当场发现
- 锁屏不影响签到；电脑插电时睡眠会自动唤醒执行；错过的任务开机后补跑
- 微信推送：成功、失败、需人工处理都推，标题直接写明结果
- 打开 exe 即看今日考勤状态，可手动签到 / 刷新 / 改配置 / 开关自动签到

## 安装

1. 把 `lazy-clerk.exe` 放进一个固定目录，比如 `D:\tools\lazy-clerk\`
2. 双击打开，第一次使用会引导你配置工号和密码
3. 配置完成后按提示开启自动签到，就全部完成了

## 使用

双击 exe 显示今日考勤状态和功能菜单：

```
1. 立即签到      2. 刷新状态      3. 更改配置      4. 配置并启用/关闭自动签到
5. 修改签到时间（开启时可见）      0. 退出
```

也可以在终端用命令：`lazy-clerk.exe setup | sign | status | install | uninstall`。

微信推送：微信扫码登录 [sct.ftqq.com](https://sct.ftqq.com/login/) 复制 SendKey，
在菜单"更改配置"里填入即可。

## 注意事项

- 首次运行若被 Windows SmartScreen 或杀毒软件拦截，属 PyInstaller 单文件 exe 的
  常见误报，选择"仍要运行"即可
- 签到时段（上午 5:00–8:00、下午 13:00–14:30）电脑需开机；关机无法签到，
  错过时段医院会在 7:00 和 14:00 提醒你
- 日志在同目录 `sign.log`（带秒级时间，超 512KB 自动截断），配置在 `config.json`
- 换了医院平台密码：菜单选"更改配置"填入新密码；收到 🔒登录失败 推送通常就是密码失效了
- **一台电脑只装一种形态**：本工具的计划任务与宿舍版同名，同时安装会被冲突检测拦下，
  先卸载旧的再装新的

## 风险

- `config.json` 含你的医院平台密码明文（签到链路必须持有可登录的原始密码），不要发给别人
- 目标系统为 HTTP 明文协议——医院系统现状，本工具无法改变
- 仅自动化"本人按时到岗后的例行点击"，不支持也不应用于虚构出勤

## 卸载

菜单里关闭自动签到，然后删除整个目录即可，没有其他残留。

## 开发者：打包 exe

```bash
pip install pyinstaller tzdata
pyinstaller --onefile --console --name lazy-clerk --collect-data tzdata personal/main.py
# 产物在 dist/lazy-clerk.exe（约 38MB），连同本 README 分发给同事即可
```
